# Rosy Reflections

Прикрепляю два референса.

Референс 1 — стилистика: шрифты, скругления, стеклянные 

полупрозрачные поверхности, общее настроение дизайна. 

Используй именно её как основу, но замени цветовую гамму — 

сейчас тёплый оранжевый/янтарный, сделай розовую/малиновую 

гамму той же тональности (мягкая, не кислотная).

Референс 2 — состав экрана: список всех блоков и элементов, 

которые должны быть на странице (какие кнопки, карточки, 

секции, их порядок). Это чистое ТЗ по содержанию, стиль 

с него НЕ бери.

Задача: нарисуй экран со всеми элементами из референса 2, 

полностью в стилистике референса 1, но с розовой гаммой 

вместо оранжевой.
3 изображение прикрепил в качестве референса, по которому разрабатывался стиль который мы используем(1 скриншот)
