# Luminous Learn Dashboard

Я делаю образовательную платформу. Возьми структуру с моего скриншота (скриншот 1), но сделай полный визуальный редизайн в стиле референсов (скриншоты 2 - 5). Используй такие же закругления, мягкие тени, цвета и типографику. Не пиши никакой сложной логики, используй моковые (фейковые) данные. Сделай только верстку главного дашборда.
